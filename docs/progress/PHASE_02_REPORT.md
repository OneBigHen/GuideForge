## Deliberate boundaries

- Source promotion is one-way at the application boundary; Dexie remains the
  legacy input/cache table and is not treated as authoritative after Yjs
  hydration.
- This phase establishes canonical records and package portability. It does
  not certify real Docling/OCR/ASR/VLM providers, live DeepSeek generation,
  physical iPad/iPhone behavior, or production backup/restore.
- The Yjs document stores JSON-safe source/provenance records; binary source
  and scene assets remain content-addressed package assets rather than being
  copied into the collaborative document.
