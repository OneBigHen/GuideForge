# Phase 08 Report — Asset Providers, Import Safety, and Library UX

## Gate status

The Phase 08 gate is **VERIFIED NARROWLY** on the current tree. The local
asset manager now covers local-first search planning, safe self-contained GLB
and glTF inspection, fail-closed license handling, explicit OBJ/STL/STEP
conversion requirements, provenance metadata, and browser-tested inventory
flows.

This is not a claim that every external provider, CAD converter, thumbnail
pipeline, or clean-profile import has run successfully on this host.

## Delivered path

- `@guideforge/assets` adds checked logic for GLB/glTF bounds, external-resource
  rejection, triangle/vertex/material/texture counts, and conservative
  geometry-health reporting. Topology is explicitly marked as not computed.
- Provider descriptors cover Poly Haven, NIH 3D, FreeCAD Library, Kenney, and
  Quaternius. Search plans normalize and bound queries, search local metadata
  first, and produce allowlisted provider request URLs.
- Blank and unknown licenses no longer pass the embedding policy. Provider
  records without a verified license remain blocked for package use.
- `AssetMetadata.schema.json` records the persisted asset metadata contract,
  including review state, geometry health, provenance, dimensions, and
  derivative hashes.
- `AssetLibrary.importBytes` inspects before storage. Raw OBJ/STL/STEP are
  retained as explicit conversion inputs and cannot be mistaken for canonical
  scene-ready GLB assets.
- `/assets` provides the local inventory, procedural templates, safe import,
  source hashes, geometry counts, license blocks, conversion warnings, and
  provider search requests. The existing scene asset path remains intact.

## Known boundary

The provider layer deliberately stops at allowlisted search requests. No
provider credentials or unrestricted downloader were added. NIH 3D and
FreeCAD-library records require per-record license verification. OBJ/STL/STEP
conversion requires the named companion tool, and actual Blender/FreeCAD
execution is not proven here. Preview/turntable derivatives are represented
by metadata slots but are not generated by this phase. Procedural templates
remain approximations and are not manufacturer/scientific meshes.

**Gate:** VERIFIED NARROWLY — local safety, policy, metadata, and emulated
browser evidence passed; external provider, converter, derivative, and clean
profile acceptance remain unverified.
